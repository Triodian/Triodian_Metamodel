# Shared vocabulary

`schemas/common.schema.json` defines the controlled vocabularies and reusable structures every domain should use. All values are camelCase. Domains reference them with `$ref` instead of keeping their own lists.

This page is generated by `scripts/vocabulary_map.py`. For each shared definition it lists the canonical values and every field in the schemas that currently keeps its own list, with how each current value maps across.

- **lossy**: the mapping merges values that currently mean different things. Needs a decision.
- **unmapped**: the value has no shared equivalent. Either add it to the shared list or keep it as a domain-specific value.

**123 fields** keep a local list for a shared concept (657 values): 620 map directly, 22 are lossy, 15 are unmapped.
