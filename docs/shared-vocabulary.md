Domains reference them with `$ref` rather than keeping their own lists; where a domain genuinely needs extra values, it adds them alongside the shared list.

This page is generated by `scripts/vocabulary_map.py` and checked in CI. [`vocabulary-migration.json`](vocabulary-migration.json) records how the previous domain-specific values were mapped.
